# ARC Volume Overlay за TCL + Sony HT-RT3

Малко Android TV приложение, направено за TCL 98P745. Следи `Settings.System / volume_music_hdmi_arc`.

Когато стойността се промени, показва числото за около 2.8 секунди до оригиналния TCL ARC volume OSD. Не променя CEC, ARC, аудио routing или SystemUI.

APK се компилира автоматично чрез GitHub Actions.
